## Dependency audit advisories cleared and CI runners pinned to Ubuntu 26.04

**Security.** Cleared the npm audit advisories that were failing the Security workflow on `main` and on every open dependency pull request. Two of the patched packages run inside the UI server. `proxy-addr` (2.0.8), used by Express to work out the client IP behind a proxy, fixes a critical IP-spoofing bug with IPv4-mapped IPv6 addresses. `ip-address` (10.7.3), used by the rate limiter, fixes IPv6 subnet classification bugs that could let an address be grouped outside its real range. The rest were in development tooling only: `axios` (1.20.0), `brace-expansion` (5.0.12), `shell-quote` (1.12.0), `source-map-js` (1.2.2), and `basic-ftp` (6.2.2, via an override because the upstream `get-uri` has not moved off the unpatched 5.x line yet). `sprintf-js`, which has no patched release, is gone from the tree: the coverage tooling's `js-yaml` 3 now gets `argparse` 2, which does not depend on it. `npm audit` reports no moderate or higher advisories. A low-severity `katex` advisory remains, pending a `mermaid` release that moves off KaTeX 0.16.

**CI.** Workflows now run on `ubuntu-26.04` explicitly instead of `ubuntu-latest`, ahead of GitHub moving that label to Ubuntu 26.04 from October 19, 2026.
